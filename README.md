# Nodra Pay // Gaming Freelance Work & Income Ledger

A high-density, dark-mode freelance work ledger crafted specifically for **gaming freelancers, game devs, 3D/2D artists, QA playtesters, coaches, and digital creators**.

## Features

- ⚡ **Instant Screenshot & Proof Paste (`Ctrl+V`)**: Copy any screenshot (`Win+Shift+S`) and press `Ctrl+V` in the entry form to attach proof of completion.
- 🎮 **In-Game Currencies & Iranian Toman**: Native support for USD, EUR, GBP, USDT, **Iranian Toman (تومان)**, plus **Robux (R$), Valorant Points (VP), Fortnite V-Bucks, WoW Gold, OSRS GP, TF2 Keys, and Minecoins**.
- 📊 **Dense Metrics & Analytics**: KPI strip for total paid, escrow, average job realization, plus monthly earnings velocity and game breakdown charts via Chart.js.
- 🗄️ **Zero Quota Limit Storage**: Built on browser IndexedDB to safely store high-resolution image proofs.
- 🔄 **Export & Backup**: One-click CSV export and full JSON backup/restore.

## Quick Start

Simply clone the repository and open `index.html` in your favorite web browser:

```bash
git clone https://github.com/vltmk/nodra-pay.git
cd nodra-pay
# Open index.html directly in browser
```
