## What's New in Nodra Pay 2.0

- 🖤 **Pure Black (`#000000`) Glassmorphism Design**: Ambient translucent radial meshes, borderless shaded depths (`bg-white/[0.035]` to `bg-white/[0.08]`), `backdrop-blur-2xl`, and subtle top specular light lines (`ring-1 ring-white/10`).
- ⚡ **Motion (`motion/react`) Animations**: Fluid spring layout transitions, card hover lifts, modal scale-ins, and animated KPI counters.
- ⌨️ **Power-User Keyboard Shortcuts**: Press <kbd>?</kbd> anytime to open the interactive Shortcuts Guide modal.
- 🔄 **1-Click Inline Status Flip**: Click status badges directly on table rows to cycle statuses with spring feedback.
- 🧾 **Instant Proof-of-Work Receipt / Invoice Slip**: 1-click generator to pop up a branded proof-of-work receipt with attached screenshots ready to print / save as PDF.
- 🎯 **Gaming Quick-Presets**: Auto-populate fields for *Roblox 3D Assets*, *Unreal/Unity C# Script*, *Valorant Coaching*, *QA Playtests*, and *Textures*.
- 📋 **Direct `Ctrl+V` Screenshot Paste**: Instant clipboard screenshot pasting (`Win+Shift+S`) into the work modal.
- 🎮 **In-Game Currencies & Iranian Toman**: Native support for USD, EUR, GBP, USDT, **Iranian Toman (تومان)**, **Robux (R$)**, **Valorant Points (VP)**, **Fortnite V-Bucks**, **WoW Gold**, **OSRS GP**, **TF2 Keys**, and **Minecoins**.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>?</kbd> or <kbd>Shift</kbd>+<kbd>/</kbd> | Open Shortcuts Guide Window |
| <kbd>N</kbd> or <kbd>Ctrl</kbd>+<kbd>N</kbd> | Log New Gaming Work |
| <kbd>/</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd> | Quick Focus Search Bar |
| <kbd>V</kbd> | Toggle View (Dense Table ⇄ Compact Cards) |
| <kbd>A</kbd> | Toggle Analytics & Charts Drawer |
| <kbd>E</kbd> | Export to CSV |
| <kbd>B</kbd> | Full JSON Backup with Screenshots |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste Screenshot Proof (in modal) |
| <kbd>Esc</kbd> | Dismiss any Modal or Lightbox |

## Getting Started

```bash
# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
